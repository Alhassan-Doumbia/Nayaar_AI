# data/notebooks/

Notebooks Jupyter formant la documentation analytique du projet, à créer dans l'ordre :

1. `01_data_exploration.ipynb` — analyse exploratoire du dataset brut Kaggle.
2. `02_data_cleaning.ipynb` — nettoyage, doublons, valeurs manquantes, normalisation.
3. `03_feature_engineering.ipynb` — création des features métier (saison, style,
   usage, performance, profil, climat, scores de compatibilité).
4. `04_embeddings_preparation.ipynb` — textes enrichis, embeddings, préparation
   pgvector/FAISS.

Voir [Docs/PROJECT_CONTEXT.md](../../Docs/PROJECT_CONTEXT.md) section 8 pour le détail
des objectifs de chaque notebook.
