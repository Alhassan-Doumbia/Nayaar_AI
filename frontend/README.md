# frontend/

Application Next.js (**JavaScript, pas de TypeScript**) : interface du Nayaar
Assistant — chat, recherche de parfum, recherche par intention, conseil personnalisé,
suggestion de layering, explication des recommandations.

Consomme l'API exposée par `backend/`. Aucun code applicatif pour l'instant — projet
Next.js à initialiser lors de l'implémentation.

Voir [Docs/PROJECT_CONTEXT.md](../Docs/PROJECT_CONTEXT.md) section 17.
